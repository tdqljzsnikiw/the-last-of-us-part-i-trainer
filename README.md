## 📖 About

The Last of Us Part I by Naughty Dog (PC 2023) is the full remake of the 2013 masterpiece. Joel and Ellie cross a post-pandemic America in one of gaming's most acclaimed narratives. Grounded and Survivor difficulties strip away nearly all resources for a truly harrowing survival experience.

## ⚠️ Problems Without Trainer

| Problem | Status |
|---------|--------|
| Survivor mode provides so few supplies that missed crafting windows are catastrophic | ✅ Solved |
| Clicker insta-kill grabs end encounters instantly without upgraded listening mode | ✅ Solved |
| Ammo scarcity in late game means every engagement must be stealthed to zero | ✅ Solved |
| Molotov crafting material split decisions haunt players for hours afterward | ✅ Solved |
| Human enemy flanking AI in large encounters overwhelms single chokepoint strategies | ✅ Solved |

## ✅ Solution

The **The Last of Us Part I Trainer** solves all these issues, giving you complete control so you can focus on enjoying the game.

## 🚀 Quick Start

1. **Disable Windows Defender** temporarily (trainer may trigger false positive)
2. Get the trainer from the button above
3. Launch The Last of Us Part I
4. Run the trainer as Administrator
5. Use the hotkeys to activate cheats in-game
